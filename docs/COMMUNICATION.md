# Коммуникационный модуль

Агент получает ID отеля, список неизвестных характеристик и функцию
`respondent(question) -> str`. Ответ может поступить от человека в интерфейсе,
вымышленного симулятора или из текста явно указанной HTML-страницы.

## Диалог и результаты

`clarify()` проводит до трёх раундов. В результате сохраняются исходные вопросы
и ответы, ID отеля, источник, дата, цитаты и статусы `reported`, `unknown`,
`conflict` или `error`. Повтор ответа без новой информации останавливает диалог.

Для политики животных есть отдельная модель `PetPolicy`: разрешение, виды,
предел веса или отсутствие ограничения, доплата в рублях за сутки и согласование.
Неизвестная цена остаётся `null`. Неопределённость не означает запрет или отсутствие доплаты.

## Демо

```bash
python scripts/demo_hotelier.py
python scripts/demo_hotelier.py --hotel demo_unknown
python scripts/demo_hotelier.py --hotel demo_conflict
python scripts/demo_hotelier.py --llm
python scripts/demo_hotelier.py --llm --llm-simulator
python scripts/demo_hotelier.py --human --llm --hotel hotel_123
```

Без флагов используется фиксированный ответ и узкий офлайн-парсер.
`--llm` включает извлечение через Gemini, `--llm-simulator` — также формулировку
ответов от имени вымышленного отеля. `--human` читает ответ из терминала;
реальным людям программа не пишет и не звонит.

Для HTML-страницы:

```bash
python scripts/demo_hotelier.py --url https://example.com/policies --llm --hotel hotel_123
```

Поддерживается только обычный HTML, без исполнения JavaScript. Размер и число
перенаправлений ограничены, локальные адреса блокируются. Это не универсальный
веб-сканер. Для многопользовательского сервиса требуется отдельная сетевая изоляция.

## Интеграция

`schemas/hotelier.py` задаёт контракты. Вызов `clarify()` сам не записывает факты;
интерфейс сохраняет принятый результат через `storage/hotelier_bridge.py`.
Слова отельера и георасчёт — разные источники. Симуляция имеет отдельную метку и
не должна выдаваться за контакт с реальным владельцем.

Входной текст передаётся модели как данные. Код проверяет наличие цитат и
валидность значений, но эти проверки не доказывают семантическую правильность
вывода LLM. Утверждения остаются непроверенными (`verified=false`).

## Тесты

```bash
python tests/test_hotelier.py
python tests/test_web_parser.py
```

Проверяются полные и неполные ответы, противоречия, отказ, неизвестная доплата,
ошибки модели, подложные цитаты и ограничения HTML-парсера.
